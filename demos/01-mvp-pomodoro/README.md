# Demo 01 — MVP in 5 minutes

A Pomodoro timer with session stats, persistent via localStorage. Generated from a single paragraph spec.

**The original prompt:**
> Build a Pomodoro web timer. 25 min focus, 5 min rest. Start, pause, reset. Show today's count, current streak, total count. Persist across reloads. Editorial style — Georgia serif, cream background, single coral accent. No frameworks.

**Run:**
```bash
open index.html
```

**The point of the demo:** show that the gap between "I want this" and "I have this" can be five minutes if your spec is tight.
