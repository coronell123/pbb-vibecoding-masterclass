# Block 1 — First Contact

**Time:** 20 min hands-on
**Goal:** Open Claude Code in a real codebase and *resist* the urge to ask for code.

---

## Steps

1. Open this folder in your terminal:
   ```bash
   cd 01-first-contact
   ```

2. Start Claude Code:
   ```bash
   claude
   ```

3. Type — exactly — into Claude:
   > Read `parser.py`. Explain what it does in 5 bullet points. Do NOT change the file.

4. Read what Claude tells you. Discuss with your buddy: is anything wrong, missing, or oversimplified?

5. Now ask:
   > Suggest one improvement to `parser.py`. Write it as a **plan**, not as code. Maximum 8 lines.

6. Read the plan. Together with your buddy, answer these three questions:
   - What assumption did Claude make that you'd push back on?
   - Did it propose a test?
   - Is the change scoped to *one* thing, or did it grow?

7. Tell the instructor your answers when they swing by.

---

## What this exercise is *not*

It's not "make `parser.py` better". You will not edit a single character of code in Block 1.

Why? Because the first reflex most of us have with an AI coding tool is to ask for code. That reflex is what causes the failures we'll spend the next three hours fixing.

You're rewiring the reflex. Today, **plan first, code second**.
