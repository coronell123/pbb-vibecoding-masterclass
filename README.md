# Vibecoding Masterclass — Claude Code

**Course:** Mahnoor's AI course · **Format:** 4 hours, on-site · **Language:** English
**Hosted by:** Place Beyond Bytes · SUST · University of Duisburg-Essen

A 4-hour masterclass on **agentic engineering** with Claude Code. Hour 1 is a deep theory + demo session. Hours 2-4 are hands-on through the exercises in this repo.

---

## The rhythm

```
SPEC  →  PLAN  →  TEST  →  IMPLEMENT  →  VERIFY
```

Five steps. In this order. Every time.

---

## Before you arrive

1. Bring a laptop with admin rights.
2. Install **Node.js 20+** and **git**.
3. Create a free **Anthropic account** at https://claude.ai and install Claude Code:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```
4. Clone this repo and run the pre-flight:
   ```bash
   git clone https://github.com/coronell123/pbb-vibecoding-masterclass.git
   cd pbb-vibecoding-masterclass
   bash check.sh
   ```
5. If `check.sh` says **All good**, you're set. Otherwise: ping a buddy or email Elias.

## House rules

1. **Trios, not duos.** You + your buddy + Claude.
2. **Show your plan before your code.** First question you'll be asked.
3. **Evidence wins.** "It works" is not done. Show the green test.
4. **No real client data.** Synthetic only. No keys, no PII, no NDA-covered material.
